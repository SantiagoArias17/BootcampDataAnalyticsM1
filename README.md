# Tres Pistas: calculadora de ingeniería de petróleos
Aplicación web en Streamlit del Bootcamp Data Analytics for Oil & Gas (SPE Ecuador Section), Módulo 1. Combina Python con HTML, CSS y JavaScript para resolver tres cálculos de ingeniería:

Pista =	Cálculo
Producción	= IPR compuesta con punto de burbuja (lineal + Vogel)
Perforación	= Gradiente y presión hidrostática del lodo, ΔP frente a la presión de formación
Reservorios	= POES volumétrico y volumen recuperable
